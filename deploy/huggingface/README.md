# Տրանսպորտային հոսքի վերլուծություն տեսանյութով

Ավարտական աշխատանքի ցուցադրական տարբերակ. CNN (YOLOv8s), ByteTrack, գծի հատումների հաշվարկ, արագություն (կմ/ժ), խտություն և սպասարկման մակարդակ (HCM)։

**Ինչպես օգտագործել**
1. Ընտրեք «Ցուցադրական տեսանյութ» և սեղմեք «Ցույց տալ պահպանված օրինակը»՝ պատրաստի արդյունքն անմիջապես երևում է։
2. Կամ սեղմեք «Մշակել տեսանյութը»՝ տեսանյութը կմշակվի այստեղ (առանց GPU-ի, մի քանի րոպե)։
3. Կարող եք բեռնել նաև սեփական կարճ տեսանյութ (մինչև 200 ՄԲ)։

Կոդը, մոդելները և արդյունքները՝ https://github.com/marrr862/traffic-cnn
